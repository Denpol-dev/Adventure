# FOXNET
Игра представляет собой консольный симулятор управления персонажем через спутник.

## FAQ 
Как запустить игру? Если не интересует отладка, то переходите в папку Realise, в ней найдите файл Adventure.exe и запустите его. Для корректной работы игры лучше сразу развернуть консоль на весь экран, как только она откроется. Наслаждайтесь!

## Миры FOXNET

Мир по умолчанию описан в [world.json](Adventure/Worlds/default/world.json). В каталоге `levels` лежат 16 исходных квадрантов. При сборке и публикации JSON копируется рядом с игрой. Другой мир можно открыть, передав путь к его манифесту.

```powershell
dotnet run --project Adventure/Adventure.csproj -- "C:\Maps\my-world\world.json"
```

- Манифест задаёт версию схемы, GUID мира, стартовую позицию дрона и список файлов квадрантов. В каждом квадранте есть свой GUID, глобальные координаты и ссылки на соседей по GUID. Глобальный X растёт вправо, Y вниз. Локальный отсчёт начинается с `(0, 0)` в левом верхнем углу.
- `rows` хранит по строке на ряд клеток. Все строки имеют длину `width`, а их количество равно `height`. Рамка рисуется консолью. При переходе дрон сохраняет координату вдоль края и может войти только в проходимую клетку соседа.
- `objects` задаёт объекты по координатам и постоянным ID. Тип, содержимое, требуемый предмет и параметры терминала задаются отдельно от символа карты. При перемещении объекта в редакторе сохраните его ID. В одной клетке может быть несколько объектов. Консоль показывает и активирует первый из списка, а коллизии учитывают все.
- `buildings` задаёт ID зданий и их помещений. В разреженном списке `cells` можно явно назначить клетке здание и помещение, переопределить проходимость территории через `blocksMovement` и задать отдельный признак `blocksScanning`. Исходные карты ещё не размечены по помещениям.
- `WorldFiles.Load` и `WorldFiles.Save` используют общий `WorldValidator`. Редактор может менять списки квадрантов, объектов и свойств клеток через `WorldDefinition`. При сохранении новые версии файлов квадрантов записываются перед заменой манифеста. Предыдущие версии остаются в каталоге.
- JSON содержит исходное описание. Дрон, его инвентарь и экземпляры объектов создаются на игровую сессию. Для будущих сохранений можно адресовать их по ID мира, квадранта и объекта, а исследованные клетки хранить по локальным координатам квадранта.

## Экспедиция

Запусти Desktop из корня репозитория командой `dotnet run --project Foxnet.Desktop`. В разделе FOXNET Device подключись к N910VT. В новой сессии данные доступа к спутнику лежат в сообщении `unknown`. При повторном подключении консоль открывает сохранённую экспедицию. Закрытие Desktop оставляет консоль работать, а кнопка «Отключиться» останавливает её.

| Клавиша | Действие |
| --- | --- |
| `WASD` | Движение выбранного дрона или точки наведения |
| `Tab` | Переключение `Drone` → `Laser` → `Combined` |
| `F` | Список обнаруженных дронов |
| `E` | Взаимодействие с объектом под дроном |
| `C` | Один цикл зарядки в зоне станции |
| `Q` / `R` | Инструмент левой / правой руки |
| `↑` / `↓`, `Enter`, `Esc` | Выбор, подтверждение и выход из текстовых меню |

Проверить новый маршрут можно на свежей экспедиции.

1. DR-01 начинает с 28% в боксе `BAY-01` квадранта `N23S55`. Пройди вправо через своё поле в центральный коридор. Поле напротив пропускает дрон, которому назначен этот бокс. На станции нажми `C` и проверь заряд в GAh.
2. Терминал обслуживания стоит в конце коридора на `(35, 24)`. Донор `DN-01` лежит сразу за выходом на `(36, 26)`. Нажми `E` у донора и извлеки лидар или аккумулятор. Вернись к терминалу, открой нужный слот и установи модуль. При замене аккумулятора сравни остаток заряда старого и нового экземпляров.
3. Переключись на `Laser` и наведи луч на восточную часть `N23S55`. У `DR-02` координаты `(75, 12)`. После обнаружения выбери его через `F`. Вернись в `Combined` и проверь, что точка наведения следует за выбранным дроном.
4. Подведи луч к бункеру в `N23S56`. С орбиты видна крыша. Войди через проход `(24, 12)`. Без лидара внутри виден `X` по координатам дрона. Для проверки лидара выбери через `F` тот дрон, на который ты его установил, и войди в помещение. После ухода или снятия лидара разведанная геометрия остаётся тусклой.
5. Закрой консоль и подключись снова. Сверь режим, выбранный дрон, его координаты, заряд и инвентарь. Разобранные доноры и взятые предметы должны сохранить состояние. Для отдельной тестовой экспедиции можно указать собственный файл БД аргументом `--session` у Adventure.

Для ускоренной проверки разряда используй отдельную копию мира и новую тестовую БД. В копии манифеста выставь `wheelMove` выше начального запаса энергии. Каждое успешное движение тогда разрядит выбранный дрон. Обнаруживай следующие аппараты в режиме `Laser`. После разряда последнего дрона перезапусти консоль с той же тестовой БД и проверь экран Game Over.

Определение экспедиции находится в `Adventure/Worlds/default/world.json`. В нём заданы парк, доноры, накладка техстанции, разметка помещений и баланс. По умолчанию SQLite находится в `%LOCALAPPDATA%\FOXNET\session.db`. Он хранит ревизию экспедиции отдельно от профиля и переписок. Консоль владеет записью экспедиции и подтверждает команды после сохранения. Desktop получает обновления спутника через Named Pipes.
