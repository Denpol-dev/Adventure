### Требования
Для установки и запуска проекта, нужна установленная Visual Studio. Если желания отлаживать код нет, то можно обойтись просто пакетом .NET, который должен скачаться автоматически.

## FAQ 
Как запустить игру? Если не интересует отладка, то переходите в папку Realise, в ней найдите файл Adventure.exe и запустите его. Для корректной работы игры лучше сразу развернуть консоль на весь экран, как только она откроется. Наслаждайтесь!

## Миры FOXNET

Мир по умолчанию описан в [world.json](Adventure/Worlds/default/world.json). В каталоге `levels` лежат 16 исходных квадрантов. При сборке и публикации JSON копируется рядом с игрой. Другой мир можно открыть, передав путь к его манифесту.

```powershell
dotnet run --project Adventure/Adventure.csproj -- "C:\Maps\my-world\world.json"
```

- Манифест задаёт версию схемы, GUID мира, стартовую позицию дрона и список файлов квадрантов. В каждом квадранте есть свой GUID, глобальные координаты и ссылки на соседей по GUID. Глобальный X растёт вправо, Y вниз. Локальный отсчёт начинается с `(0, 0)` в левом верхнем углу.
- `rows` хранит по строке на ряд клеток. Все строки имеют длину `width`, а их количество равно `height`. Рамка рисуется консолью. При переходе дрон сохраняет координату вдоль края и может войти только в проходимую клетку соседа.
- `objects` задаёт объекты по координатам и постоянным ID. Тип, содержимое, требуемый предмет и параметры терминала задаются отдельно от символа карты. При перемещении объекта в редакторе сохраните его ID. В одной клетке может быть несколько объектов. Консоль показывает и активирует первый из списка, а коллизии учитывают все.
- `buildings` задаёт ID зданий и их помещений. В разреженном списке `cells` можно явно назначить клетке здание и помещение, переопределить проходимость территории через `blocksMovement` и задать отдельный признак `blocksScanning`. Исходные карты ещё не размечены по помещениям.
- `WorldFiles.Load` и `WorldFiles.Save` используют общий `WorldValidator`. Редактор может менять списки квадрантов, объектов и свойств клеток через `WorldDefinition`. При сохранении новые версии файлов квадрантов записываются перед заменой манифеста. Предыдущие версии остаются в каталоге.
- JSON содержит исходное описание. Дрон, его инвентарь и экземпляры объектов создаются на игровую сессию. Для будущих сохранений можно адресовать их по ID мира, квадранта и объекта, а исследованные клетки хранить по локальным координатам квадранта.
